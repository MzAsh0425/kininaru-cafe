# きになるカフェ ☕️

気になったカフェのリンクを貼るだけで、公式HP・食べログ・SNSなどの関連リンク、写真、地図、営業時間などをまとめて身内で共有できる iPhone 向け Web アプリです。

- **画面**: GitHub Pages（ビルド不要の静的サイト / ホーム画面に追加すればアプリのように使えます）
- **データ・処理**: Google スプレッドシート + Google Apps Script（GAS）
  - スプレッドシート … 部屋・メンバー・カフェ情報（直接見て編集もできます）
  - Google ドライブ … 収集した写真・アップロードした写真
  - GAS … 画面からの API、リンク先の情報収集
- **AI補完（任意）**: Gemini API キーを設定すると、Gemini が Google 検索で公式HP・食べログ・Instagram・営業時間などを探して補完します

必要なのは Google アカウントだけです。

## 使い方

1. 合言葉と自分の名前を入れて入室（同じ合言葉を入れた人と同じ部屋になります）
2. 右下の「カフェを追加」からリンクを貼る → 「情報を収集中…」のカードが出る
3. 数十秒〜1分ほどで写真・基本情報付きのカードになります
4. カードをタップすると、写真・リンク・営業時間・地図・メモなど全情報を表示。「編集」から全項目を修正できます

投稿者ごとに色分けされ（色は右上の名前から変更可）、「自分」「相手」「まだ行ってない」「行った」で絞り込めます。

## 情報収集のしくみ

1. 貼られたページを取得し、JSON-LD（構造化データ）・OGP・店舗情報の表（住所/営業時間/定休日…）・SNSリンクを抽出
2. Gemini API キーがあれば、Gemini が Google 検索とURL読み込みで店舗を特定し、関連リンクと基本情報を補完（AIが挙げたURLは実在チェックしてから採用）
3. 見つかった食べログ・公式HPも取得して、写真と情報を追加
4. 写真は Google ドライブの「きになるカフェ_写真」フォルダにコピー（リンク切れ防止）
5. 途中で止まったものは 5 分おきの定期処理が拾い直します

> 食べログや公式HPのリンクは AI なしでもかなりの情報が取れます。Instagram のリンクだけだと店名程度しか取れないため、AI補完の設定をおすすめします。Gemini API には無料枠があり、2人で使う程度なら無料枠に収まる見込みです（Google 検索グラウンディングは検索回数に応じた課金対象なので、最新の料金は https://ai.google.dev/gemini-api/docs/pricing を確認してください）。

## セットアップ（15分ほど）

### 1. スプレッドシートと GAS を用意する

1. [Google スプレッドシート](https://sheets.new) で新しいシートを作る（名前は「きになるカフェ」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身をすべて消し、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付けて保存（💾）

### 2. Gemini API キーを登録する（任意）

1. https://aistudio.google.com/apikey で API キーを発行
2. Apps Script の左メニュー **⚙ プロジェクトの設定 → スクリプト プロパティ → スクリプト プロパティを追加**
   - プロパティ: `GEMINI_API_KEY` / 値: 発行したキー
   - （任意）`GEMINI_MODEL` … 使うモデル。未設定なら `gemini-3.8-flash`。安くしたい場合は `gemini-3.5-flash-lite` など

### 3. 初期設定を実行する

1. エディタ上部の関数選択で **`setup`** を選び **▶ 実行**
2. 権限の確認が出たら自分のアカウントを選ぶ → 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動（安全ではないページ）** → **許可**
   （自分で作ったスクリプトなので問題ありません。シート・ドライブ・外部サイト取得・定期実行の権限を使います）
3. スプレッドシートに `rooms` `members` `cafes` シートができ、ドライブに写真用フォルダが作られます

### 4. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** → 種類の ⚙ から **ウェブアプリ**
2. 設定
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
3. **デプロイ** を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

### 5. 画面に URL を設定する

[`js/config.js`](js/config.js) の `API_URL` をコピーした URL に書き換えて push すると、数分で GitHub Pages に反映されます。

### 6. iPhone で使う

1. Safari で https://mzash0425.github.io/kininaru-cafe/ を開く
2. 共有ボタン → **ホーム画面に追加**
3. 相手にも URL と合言葉を伝える

#### （おまけ）共有シートから直接追加するショートカット

「ショートカット」アプリで以下を作ると、Instagram や Safari の共有ボタンから一発で追加画面を開けます。

1. 新規ショートカット → 設定で「共有シートに表示」をオン、入力を「URL」「テキスト」に
2. アクション「URLエンコード」で「ショートカットの入力」をエンコード
3. アクション「テキスト」に `https://mzash0425.github.io/kininaru-cafe/?add=` + エンコード結果
4. アクション「URLを開く」

## GAS のコードを更新したとき

`gas/Code.gs` を変更したら、Apps Script に貼り直して保存し、**デプロイ → デプロイを管理 → ✏️ 編集 → バージョン: 新バージョン → デプロイ**。
（「新しいデプロイ」にすると URL が変わってしまうので注意）

## スプレッドシートを直接編集するとき

- 店名・営業時間などは普通に書き換えて OK です（アプリに反映されます）
- `links` `photos` 列は JSON 形式なので、アプリの編集画面から変えるのがおすすめです
- 1 行目の見出しと列の順番は変えないでください

## セキュリティについて

- 合言葉は端末上で SHA-256 ハッシュ化され、平文は送られません。すべての操作で合言葉ハッシュを確認しています
- ウェブアプリの URL 自体は誰でもアクセスできますが、合言葉を知らないとデータは読み書きできません
- 写真はドライブ上で「リンクを知っている全員が閲覧可」になります
- 身内向けの簡易な仕組みなので、推測されにくい合言葉を使ってください
